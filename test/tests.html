Seclusa Pyramid tests

Plain ES modules, no build step, no test runner. Every assertion runs against the real engine in a real browser. The card-engine suites are ports of the JUnit/TypeScript tests that ship with the Android app; test names are unchanged where they already existed. The shell suites cover the app around the engine: the security and privacy invariants that regress silently, and the theme bootstrap every game frame loads.
