# Seclusa Pyramid

Pair cards and clear the pyramid. Local only.

This game runs in the browser. No sign-up, no adverts, and nothing about how you
play is sent anywhere. Add it to your home screen and it works offline.

- Version 0.1.2
- Play: https://ambr3.github.io/seclusa-pyramid/
- Source: https://github.com/ambr3/seclusa-pyramid
